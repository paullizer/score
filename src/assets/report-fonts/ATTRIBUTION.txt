Load the local assets as ArrayBuffers and pass
{ fonts: { regular: ArrayBuffer, bold: ArrayBuffer } } to the report writer.
No runtime font downloads or system/proprietary fonts are required.
Noto Sans does not cover every writing system. Writers must check the actual
embedded font's glyph coverage and reject unsupported text explicitly.
